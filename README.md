## ✨ Key Features
- **Interactive Data Science Terminal**: Built-in command shell (`whoami`, `skills`, `projects`, `education`, `contact`) right in the hero section.
- **Live Student Grade Predictor (ML Simulator)**: Interactive sliders (`Weekly Study Hours`, `Prior Grade G1`, `Absences`) updating predicted scores and **Chart.js** trajectories in real time.
- **Interactive Data Lab**: 4 live visualizations (Grade Distribution with cohort toggle, ML Model Accuracy comparison, Skills Radar, Study Hours vs Performance).
- **3D Tilt Project Cards & Detail Modals**: Filterable showcase (`Data Science & ML`, `Full-Stack Web`, `Automation`) with architecture highlights.
- **Interactive Skills Matrix & Quick Menu (`Ctrl+K`)**: Filterable stack + keyboard command palette + mouse-reactive constellation canvas.
- **Admin Dashboard (`admin.html`)**: Manages contact messages and inquiries via `localStorage`.

## 🛠️ Tech Stack
`HTML5` · `CSS3 (Glassmorphism & Grid)` · `Vanilla JavaScript (ES6+)` · `Chart.js` · `SVG Animations` · `GitHub Pages`
